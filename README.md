# x-loam

Chrome / Edge 口语化润色扩展及可复用的中文写作 Skill。

## 安装

需要 Chrome 或 Edge。运行源码测试需要 Node.js 与 npm。

克隆仓库后，在项目根目录执行以下步骤。

打开浏览器扩展管理页，开启开发者模式并选择「加载已解压的扩展程序」，指向 extension/。

## 使用

设置自己的模型服务，选中网页文字或打开扩展，提交润色请求，检查结果后复制或替换。

## 检查

```sh
npm ci && npm test
```

## 说明

仓库包含源码与启动所需的示例。模型、平台或推送服务的凭据由使用者在本机配置。
