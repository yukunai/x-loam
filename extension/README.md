# 口语化润色（Spoken Polisher）浏览器插件

选中网页上的文字 → 自动弹出快捷工具条 → 点「润色」→ 在选区下方生成结果卡片。

支持三家 API 任选：**Claude（Anthropic）/ DeepSeek / ChatGPT（OpenAI）**。文风是口语化的「微信群聊 / 朋友圈」风格：短句、有个人观点、保留事实、不端着。

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）。
2. 右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本 `extension/` 文件夹。

## 配置

点浏览器工具栏上的插件图标 → 弹出小窗显示配置状态，从这里进两个设置分页：

**「API 设置」分页**——三家大模型各一张卡片，任选一家或都填：
- 填 API Key：
  - Anthropic：https://console.anthropic.com/ （`sk-ant-...`）
  - OpenAI：https://platform.openai.com/ （`sk-...`）
  - DeepSeek：https://platform.deepseek.com/ （`sk-...`）
- 在常用的那家卡片上勾「设为默认模型」
- 模型名一般不用改，默认优先响应速度：Claude → `claude-haiku-4-5-20251001`，ChatGPT → `gpt-5.4-mini`，DeepSeek → `deepseek-v4-flash`。
- 如果临时需要更强质量，可以点「填入最强模型」后保存；润色、改写、翻译通常不需要默认使用最强模型。
- 点「保存 API 设置」

**「技能管理」分页**——内置「口语化润色」技能 + 你自己加的技能：
- 添加：填技能名称 + 技能指令（告诉模型怎么改写）→ 点「添加技能」
- 删除：自定义技能卡片上点「删除技能」；内置技能不可删
- 添加后，在网页选中文字弹出的工具条设置里就能切换使用

## 使用

- **选中即弹**：在任意网页用鼠标选中文字，松开后选区下方弹出横向快捷工具条（复制触发同样有效）。
- **右键触发**：选中文字 → 右键 →「润色成口语化文风」。
- **润色**：点工具条里的「润色」，选区下方会生成豆包式结果卡片。
- **插入/替换**：在输入框、textarea 或 contenteditable 编辑器里选中文字时，结果卡片底部可直接「插入」或「替换」；普通只读网页不会改页面内容。
- **复制结果**：点结果卡片底部「复制」即可复制润色结果。
- **切换技能/模型**：点工具条里的「⋯」展开设置区，临时切换技能和模型；不选就用默认。
- **有声阅读**：点工具条或结果卡片里的「朗读」，用浏览器自带语音读出润色结果（没有结果时读原文）；再点一次停止。不需要联网调 API，也不额外收费。

## 自定义技能

内置技能是「口语化润色」。想要别的改写风格，可以自己加：

1. 点插件图标打开设置面板，找到「自定义技能」。
2. 填技能名称（如「转正式邮件腔」）和技能指令（告诉模型怎么改写，这段话会作为 system prompt）。
3. 点「添加技能」。之后在网页选中文字时，工具条设置区的技能下拉框里就能选到它。
4. 不要的技能点「删除」即可；内置「口语化润色」不可删除。

注意：140% 长度上限和段落独立规则对所有技能统一生效。

## 长度与段落规则（按需求设定）

- 输入长短不限：十几二十个字的短句到 1000 字的长文都能润色/改写。
- 输出会尽量不超过原文有效字数的 140%；但使用「润色」处理 50 字以内原文时，会在不改变原意、不新增事实的前提下丰富表达，扩到 50 字以上。
- 段落独立原则：每个段落脱离全文也能被准确理解，不出现「上述」「前文」「这里」「这样做」这类依赖上下文的表达。
- 每个段落只讲一个信息点，单段不超过 120 字。
- 如果模型输出超出 140%，插件也会直接显示完整内容，不自动压缩、不阻断生成。

## 安全与隐私

- API Key 只存在浏览器本地（`chrome.storage.local`），不上传任何第三方服务器。
- 文字内容只发给你自己选择的模型服务商（Anthropic / DeepSeek / OpenAI 官方接口），别在不信任的场景润色敏感内容。
- Key 输入框是密码态显示；插件不会把 Key 写进润色结果或日志。

## 常见问题

- **弹窗没出来**：确认选中的是网页正文选区（部分站点禁止脚本注入，如 chrome:// 页面、商店页面）。
- **报「还没有配置 API Key」**：工具条里临时选的模型和你填了 Key 的那家要对得上。
- **报 HTTP 401/403**：Key 不对或额度用完。
- **报模型不存在**：该服务商下线了默认模型，去设置里改成现役模型名。
- **朗读没声音**：确认浏览器支持 Web Speech API，并检查系统语音输出和音量。

## 开发

- 核心逻辑在 `polish-core.js`（UMD，浏览器和 Node 共用），测试在仓库根目录 `tests/`，跑 `npx jest`。
- 技能版（命令行/Agent 用）在 `../skills/spoken-polisher/`，CLI：`node ../skills/spoken-polisher/scripts/polish.cjs --provider claude "文本"`。
